Put exported browser cookies here for URL sites that need login.

Examples:
  cookies/facebook_cookie.txt   (Facebook)
  cookies/youtube_cookie.txt    (YouTube)
  cookies/cookies.txt           (generic)

Export steps:
1. Install browser extension "Get cookies.txt LOCALLY"
2. Open the site while logged in (facebook.com, youtube.com, etc.)
3. Export and save the .txt file in this folder

In setlist.json:
  "cookies": "facebook_cookie.txt"

The tool reads files from the cookies/ folder automatically.

Playlists on your computer and phone

Pick the download for your system.

Trim Playlist plays your files and can download or trim a video URL. Choose the package for your system, or open the same screen in the browser.

Enter the player

Windows installer

Run the setup file, then open Trim Playlist from the Start menu. You can add a desktop shortcut during setup.

TrimPlaylist-Setup.exe
Download .exe

Linux

Unzip the folder and run start.sh. On Debian or Ubuntu, install libgtk-3-0 and libwebkit2gtk-4.1-0 first.

TrimPlaylist-Linux.zip
Download Linux

Android 0.3.2

Install the APK on the phone. Trim cuts a download from Start to End, and cookie files are created in the app.

TrimPlaylist-Android.apk
Download APK

iPhone and iPad 0.3.2

Install the IPA with your Apple ID. The phone app keeps playlists, trim, and cookie files on the device.

Trim Playlist.ipa
Download IPA

macOS and NixOS

On a Mac, install Python 3 and run start-macos.command. On NixOS, run nix develop, then python trim_playlist_app.py.

TrimPlaylist-Other-OS.zip
Download zip

In Trim URL, authentication is Cookie file, Extension account, Platform account, or No authentication. Extension account is the browser connection: install Trim Playlist Account Connector, then choose Connect with the extension. Platform account signs in inside the app window.

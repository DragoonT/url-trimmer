A playlist, and a way to trim a URL

Trim Playlist

Keep a playlist of files on your computer or phone. When the track you want is a video URL, open Trim URL and save the whole file, or keep only the part from Start to End. The same screen is the desktop window, the browser, and the phone apps. Playlists, cookie files, and downloads stay on that device.

The screens

Trim Playlist

The playlist stays with the music

Playlists are listed on the left. Open one, add a file from the computer, and play it in the same window. In this screen, Evening piano is an audio track and Acoustic session is a video. Rename or delete a playlist from the same place.

On the phone the playlist is the same idea. The files stay on that phone. A download is not added to a playlist on its own. Add it with the file picker when you want it in the list.

Trim URL

A video URL becomes a file

Open Trim URL from the title at the top left. Trim Playlist in that same menu returns to the player. Paste the video address. Full download keeps the whole file. Trim keeps the part from Start to End.

Choose MP4 video or MP3 music, and a video quality. The file is saved on that computer or phone, under its original title. You can raise the volume multiplier before the download starts. 1 is the original volume. 2 is louder.

How a private video is opened

A public video can use no authentication. A private one needs one of the other three. The phone app uses a cookie file or a platform account. It does not use the browser extension.

  1. Cookie fileChoose Create new, then Manual .txt or Import .txt file. Manual asks for a name and lets you type the cookie text. Import takes a cookie .txt you already have. The file is saved as .txt and selected for the download.
  2. Extension accountThis is the browser connection. Install Trim Playlist Account Connector, then choose Connect with the extension. The extension opens the platform and saves the session while Trim Playlist is running on this computer.
  3. Platform accountSign in inside the Trim Playlist window, the same login page the app uses. It does not use the extension.
  4. No authenticationUse this when the video is public and does not need a signed-in account.
